Les images sont en ligne sur capconseils.net : la signature est prête à l'emploi. Comme toute signature d'entreprise, le logo n'apparaît chez le destinataire qu'une fois les images autorisées — la plupart des messageries les bloquent au premier message reçu d'un nouvel expéditeur, puis les affichent d'elles-mêmes ensuite.

Méthode 1 — le bouton « Copier la signature »

  1. Ouvrir cette page dans Chrome ou Edge, puis cliquer sur Copier la signature en haut.
  2. Outlook classique : Fichier → Options → Courrier → Signatures → Nouveau. Nommer la signature, coller dans le cadre du bas, Enregistrer.
  3. Nouvel Outlook ou Outlook sur le web : Paramètres (roue dentée) → Courrier → Rédiger et répondre → Signatures électroniques. Coller, enregistrer.
  4. Gmail : Paramètres (roue dentée) → Afficher tous les paramètres → onglet Général → Signature → Créer. Coller, puis descendre en bas de la page et cliquer sur Enregistrer les modifications — Gmail ne sauvegarde pas tout seul.
  5. Affecter la signature aux nouveaux messages et aux réponses et transferts : ce sont deux réglages distincts.

Si le bouton ne réagit pas, sélectionner la signature à la souris et faire Ctrl+C : cliquer juste avant le logo, puis faire glisser jusqu'à la fin de la mention de confidentialité. Copier depuis la page affichée, jamais depuis le code source.

Méthode 2 — dépôt du fichier (Outlook classique sur Windows)

Plus fiable que le copier-coller, qui abîme parfois les tableaux.

  1. Fermer Outlook.
  2. Ouvrir l'explorateur, saisir %APPDATA%\Microsoft\Signatures dans la barre d'adresse.
  3. Y déposer ce fichier renommé Cap Conseils.htm.
  4. Rouvrir Outlook : la signature « Cap Conseils » apparaît dans la liste.

Pour finir

  1. S'envoyer un message à soi-même, puis le relire sur mobile et depuis une adresse extérieure (Gmail par exemple) : c'est là que les images manquantes se voient.
  2. Pour les collaborateurs, dupliquer la signature : seuls le nom et la fonction changent.
